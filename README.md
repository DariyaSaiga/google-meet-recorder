# ShaiNote Recorder

Chrome Manifest V3 extension для локальной записи браузерных встреч. Запись сохраняется на компьютер в формате `.webm`; отдельная сборка не требуется.

## Поддерживаемые платформы

| Платформа | Поддерживаемые адреса |
| --- | --- |
| Google Meet | `https://meet.google.com/*` |
| Microsoft Teams Web | `https://teams.live.com/*` — проверена Teams Personal, включая `/v2/` |
| Zoom Web | `https://app.zoom.us/wc` и `https://app.zoom.us/wc/*` |

Другие Teams/Zoom domains пока не подключены. Zoom controls и плавающая кнопка находятся в meeting iframe; запись захватывает всю браузерную вкладку.

## Основные функции

- Плавающая кнопка Record / Stop («Запись» / «Стоп»), перетаскивание и таймер записи.
- Только аудио или аудио + видео вкладки.
- Опциональная запись микрофона и смешивание звука вкладки с микрофоном.
- Звук встречи остаётся слышен во время записи.
- Ручная остановка и автоматическое сохранение после выхода из встречи или закрытия вкладки.
- Сохранение в Downloads, запрос места каждый раз или запись в выбранную папку.
- Только локальная запись: без облачной загрузки.

## Установка для разработки

1. Откройте `chrome://extensions` в Chrome.
2. Включите **Developer mode / Режим разработчика**.
3. Нажмите **Load unpacked / Загрузить распакованное расширение**.
4. Выберите папку проекта.
5. После изменений кода нажмите **Reload / Обновить** у расширения и обновите вкладки встреч, чтобы загрузить новые content scripts.

Проект использует обычные HTML, CSS и JavaScript, без сборщика.

## Использование

1. Откройте поддерживаемую браузерную встречу.
2. Войдите во встречу — появится плавающая кнопка записи.
3. При необходимости один раз нажмите иконку расширения для invocation/доступа `tabCapture`, затем закройте popup.
4. Нажмите **Запись**. Если появилось «Разрешить запись», нажмите иконку расширения: ожидающий START повторится автоматически.
5. Остановите запись кнопкой **Стоп**, выйдите из встречи или закройте её вкладку.
6. Файл сохранится согласно выбранному режиму. При запросе места сохранения подтвердите диалог.

## Настройки

Настройки открываются обычным кликом по иконке расширения. Страница также доступна через **Параметры расширения**.

- **Только аудио / Аудио + видео** — во втором режиме записывается изображение вкладки.
- **Микрофон ON/OFF** — добавляет собственный голос в запись. При необходимости нажмите «Разрешить микрофон» и предоставьте доступ на отдельной странице.
- **Загрузки автоматически** — сохранение через Chrome Downloads.
- **Спрашивать каждый раз** — диалог выбора места сохранения.
- **Выбранная папка** — выбор папки и разрешение на запись. При потере доступа используйте «Разрешить доступ». Если папка недоступна или имя файла уже существует, расширение переходит к диалогу сохранения.

Настройки сохраняются в `chrome.storage.local` (`gmrSettings`) и применяются при следующем старте записи. Handle выбранной папки хранится в IndexedDB.

## Имена файлов

```text
Meet_<meeting-id>_<YYYY-MM-DD_HH-MM>.webm
Teams_<meeting-id>_<YYYY-MM-DD_HH-MM>.webm
Zoom_<meeting-id>_<YYYY-MM-DD_HH-MM>.webm
```

Если ID недоступен, используется `<Platform>_meeting_<YYYY-MM-DD_HH-MM>.webm`, например `Teams_meeting_2026-10-13_18-30.webm`. Дата и время формируются при сохранении в локальном часовом поясе браузера.

## Архитектура

| Компонент | Назначение |
| --- | --- |
| `content.js` / `content.css` | Общая кнопка, таймер, drag, сообщения START/STOP и UI lifecycle |
| `platforms/google-meet.js` | Google Meet detection |
| `platforms/teams.js` | Teams Web detection |
| `platforms/zoom.js` | Zoom Web detection внутри meeting iframe |
| `service-worker.js` | Управление записью, `chrome.tabCapture.getMediaStreamId`, offscreen, stop/save, имена файлов и lifecycle |
| `offscreen.html` / `offscreen.js` | Получение media streams, AudioContext mixing, MediaRecorder, Blob и запись в выбранную папку |
| `popup.html` / `popup.css` / `popup.js` | Настройки и передача `EXTENSION_INVOKED` в content script |
| `request-mic.html` / `request-mic.css` / `request-mic.js` | Получение разрешения микрофона |

`chrome.tabCapture` захватывает всю вкладку. `AudioContext` смешивает tab audio и опциональный микрофон; звук вкладки направляется также на динамики, микрофон не воспроизводится обратно. `MediaRecorder` формирует запись `.webm`. File System Access API записывает файл в выбранную папку, IndexedDB сохраняет directory handle.

Zoom lifecycle привязан к `frameId` / `documentId`. При выходе frame worker завершает запись независимо от старого content script. Проверка существования документа позволяет восстановиться после stale capture, не останавливая подтверждённую живую запись. Технические префиксы логов `[GMR]` сохранены.

## Permissions

| Permission | Зачем нужен |
| --- | --- |
| `tabCapture` | Захват звука и, при выбранном режиме, видео вкладки |
| `activeTab` | Временный доступ после клика по иконке расширения для invocation/capture flow |
| `offscreen` | Offscreen-документ для media API вне service worker |
| `downloads` | Сохранение через Chrome Downloads и диалог выбора файла |
| `storage` | Сохранение настроек расширения |
| `webNavigation` | События навигации и проверка существования Zoom meeting iframe/document для stop/save и stale recovery |

Content scripts ограничены адресами из таблицы поддерживаемых платформ. `all_frames: true` включён только для Zoom. Отдельных `host_permissions` нет. Offscreen-документ создаётся worker с причиной `USER_MEDIA`.

## Проверки и ограничения

Ручная регрессионная проверка текущей версии пройдена для Google Meet, Teams Web и Zoom Web: Record/Stop, звук, сохранение, выход из встречи, закрытие вкладки, настройки и режимы записи/сохранения. Для Zoom дополнительно проверен новый старт после выхода без stale capture.

- Поддерживаются только браузерные версии; native Teams/Zoom apps не поддерживаются.
- Запись локальная; нет cloud upload, transcription, backend или аккаунтов расширения.
- Изменения DOM платформ могут потребовать обновления adapters.
- Закрытие вкладки проверено; завершение процесса Chrome или авария не равнозначны закрытию вкладки и не гарантируют сохранение.
- Длительная **60-минутная запись ещё НЕ проходила формальное тестирование**.

Проверка синтаксиса:

```sh
node --check content.js
node --check popup.js
node --check service-worker.js
node --check offscreen.js
node --check request-mic.js
node --check platforms/google-meet.js
node --check platforms/teams.js
node --check platforms/zoom.js
git diff --check
```
