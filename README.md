# Google Meet Recorder

Расширение для Google Chrome, которое позволяет записывать Google Meet локально на компьютер.

## Что использовалось

- JavaScript
- HTML
- CSS
- Chrome Extension Manifest V3
- Chrome Tab Capture API
- MediaRecorder API
- Web Audio API
- IndexedDB

## Установка

1. Скачать проект из Git.
2. Открыть в Chrome:
   `chrome://extensions`
3. Включить **Режим разработчика**.
4. Нажать **Загрузить распакованное расширение / Load unpacked**.
5. Выбрать папку проекта `google-meet-recorder`.
6. Закрепить расширение на панели Chrome.

## Сборка

Отдельная сборка не требуется.

Расширение написано на обычных HTML, CSS и JavaScript и запускается напрямую из папки проекта через **Load unpacked**.

Для публикации расширения папку проекта можно упаковать в ZIP-архив.

## Использование

1. Открыть Google Meet и войти во встречу.
2. При необходимости нажать на иконку расширения.
3. Нажать кнопку **Запись**.
4. Для завершения нажать **Стоп**.

Запись сохраняется в формате `.webm`.

Настройки открываются через правый клик по иконке расширения → «Параметры».

В настройках можно выбрать:

- только аудио или аудио + видео;
- запись микрофона;
- способ сохранения файла.
